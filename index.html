Zoho CRM · Web-to-Lead

Launch a Conversion-Ready Lead Form

Use this template inside Zoho CRM’s Web-to-Lead builder or deploy it as a standalone page. Replace the placeholders below with your actual Zoho CRM form tokens and field aliases.

  1. 1. Generate tokens. In Zoho CRM, head to Settings → Channels → Webforms, create a new form, and copy the hidden field values (e.g. xnQsjsdp, xmIwtLD).
  2. 2. Swap field aliases. Ensure each name attribute mirrors the CRM field API names (e.g. Last Name, custom fields like LEADCF1).
  3. 3. Configure redirect. Point returnURL to your thank-you page and enable Captcha / Double Opt-In if needed.
  4. 4. Test & publish. Submit a test lead, verify it lands in Zoho, then embed this markup on your site or landing page.

Need tracking? Wrap this form with Zoho PageSense or your analytics scripts after publishing.
